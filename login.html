Configurar Google Authenticator

Escaneie o QR code com o aplicativo Google Authenticator (Android/iPhone) ou digite o segredo manualmente. Depois informe o código exibido para confirmar.

Passo 1: baixe o Google Authenticator (Play Store / App Store).
Passo 2: toque em + → Escanear código QR e aponte para o quadro acima (ou adicione por chave de configuração).
Passo 3: digite o código de 6 dígitos gerado para confirmar a ativação.
